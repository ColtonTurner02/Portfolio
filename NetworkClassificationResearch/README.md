# COLL 400 Research

This repository contains the work from a semester-long research project conducted as part of **COLL 400**.  
In collaboration with three classmates, we researched and designed machine learning models to **analyze and classify network traffic based on its origin**.  

## Project Overview
- Explored different machine learning approaches for traffic classification  
- Collected and formatted real network traffic data  
- Trained and tested multiple models to evaluate accuracy and performance  

## Repository Contents
- **Model.ipynb** – Jupyter Notebook containing the Python code used for:
  - Data collection and preprocessing  
  - Training and evaluation of machine learning models  
  - Experimental results and analysis  

## Skills & Tools
- Python (NumPy, pandas, scikit-learn)  
- Machine Learning model design and evaluation  
- Data preprocessing and feature engineering  
- Collaborative research and technical writing
